# 🎵 Emotion-Based Music Recommendation System

An intelligent music recommendation system that detects the user's emotional state and recommends suitable music based on the detected emotion.

## 📌 Project Overview

The Emotion-Based Music Recommendation System is designed to provide personalized music recommendations based on the user's current emotional state.

The system analyzes user input through facial expressions and uses machine learning techniques for emotion detection. The detected emotion is then mapped to suitable music, which can be opened through Spotify.

## 🎯 Objectives

- Detect the user's emotional state.
- Classify emotions using machine learning techniques.
- Map detected emotions to suitable music.
- Provide personalized music recommendations.
- Integrate Spotify for music retrieval and playback.
- Provide a simple and user-friendly interface.

## 🔍 Emotion Detection

The system processes facial input and uses an emotion detection model to identify the user's emotional state.

The project uses a TensorFlow Lite model for emotion classification.

## 🎵 Music Recommendation

The detected emotion is mapped to a suitable music search.

Example mappings used in the application include:

| Emotion | Music Recommendation |
|---|---|
| Happy | Happy songs |
| Sad | Sad songs |
| Angry | Calm music |
| Neutral | Chill music |

## 📱 Application Flow

1. The application starts the camera.
2. The user's face is detected.
3. The facial input is processed.
4. The emotion detection model predicts the emotion.
5. The detected emotion is displayed.
6. A suitable music recommendation is generated.
7. Spotify is opened with the corresponding music search.
